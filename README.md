Git — мой конспект

1. Что такое Git

Git — распределённая система контроля версий. Она позволяет отслеживать изменения в файлах, сохранять историю проекта и работать над ним совместно с другими разработчиками.

2. Основные понятия

Репозиторий — хранилище проекта и его истории изменений.

Коммит (commit) — сохранённое состояние проекта.

Ветка (branch) — отдельная линия разработки.

Клонирование (clone) — создание локальной копии удалённого репозитория.

Форк (fork) — создание копии репозитория в своём аккаунте GitHub.

GitHub — платформа для хранения Git-репозиториев и совместной разработки.

Merge — объединение изменений из разных веток.

Origin — стандартное имя удалённого репозитория.
